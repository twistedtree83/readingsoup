# S1 — Walking skeleton: solo mode, Soup, end to end

Issue: #24 · Branch: `sprint/soup-mvp` · Status: **shipped**

## What shipped

A visitor lands on the site, taps *Try it yourself*, is shown a passage with the
word gaps removed and letter spacing collapsed, plays a card, and watches the
text resolve. Wrong cards do nothing. Unlimited attempts, no timing, no score.

Verified in-browser end to end: Soup renders `AttachpanelCtothelongbracket…`,
a wrong card leaves it byte-identical, the correct card restores
`Attach panel C to the long bracket…`, and *done* advances to the catalogue.

## Decisions taken

- **`mangle` returns `{ render, tokens }`, not a bare `Token[]`.** Passage-level
  presentation (Soup's tracking, Fog's contrast) is a render mode; per-token
  instructions (expiry, offset) are on the tokens. The PRD's arrow was
  indicative. `renderedText(result)` joins using the render mode's separator and
  is what the "never reconstructs the source" invariant asserts against.
- **`IMPLEMENTED` in `conditions.js` is the single edit point** for adding a
  condition. `mangle` throws for anything not listed, the solo tour reads from
  it, and the cross-condition tests loop it. S3–S7 each append one entry.
- **Word gaps render as real separators**, not a CSS `::before`. The pseudo-
  element looked right but left `innerText`, copy/paste and assistive tech
  seeing unspaced text. The DOM should match what the eye sees.
- **The correct card is necessarily present in the hand**, so the privacy test
  asserts nothing *marks* it (`fixedBy`, `correct`, `answer`…) rather than that
  it is absent. First draft of that test was wrong and was corrected.

## Gates added

- `npm run verify` = `bun test` + purity + privacy.
- **Purity gate** fails the build on `Date.now`, `new Date`, `Math.random`,
  `document`, `window`, `localStorage`, `process`, `node:` imports or `console`
  anywhere in `src/core`. Time arrives as an event field; randomness must be
  seeded through the event.
- **Privacy suite** asserts no non-reader view carries passage content, an
  unknown participant gets a safe view rather than a crash, and no view marks
  the correct card.

## Left for later slices

## Note for whoever picks up S3–S7

Add the condition to `IMPLEMENTED`, add a `case` in `mangle`, add its tuning
constants to `CONFIG`, and the tour picks it up automatically. Keep the core
pure — the purity gate will catch you.
