# S7 — Condition: Butterfingers (solo form)

Issue: #30 · Branch: `sprint/soup-mvp` · Status: **shipped**

## What shipped

A typed task rather than a reading one. The participant is given a sentence and
simply cannot get it out. Verified in-browser, typed character by character:

> intended · `The wombat requires a permit before crossing.`
> came out · `Tebatr qeueis a prit befocerosin.`

12 characters lost. A wrong card changed nothing; `Give them a scribe` restored
clean input.

## Decisions taken

- **Each keystroke's fate depends only on its index and the seed.** Backspacing
  therefore never retroactively rewrites what came before, which it would if the
  mangle were recomputed over the whole buffer with a rolling generator. A test
  covers this directly.
- **No target matching, no threshold, no score.** At a 20% drop rate an accurate
  match is unachievable, and any threshold is a scoring system in disguise —
  ruled out by the PRD. The round ends when the participant taps done, exactly
  like every other round.
- **Output is displayed with no corrections, squiggles or highlighting.** The
  input carries `spellcheck="false"`, `autocorrect="off"`, `autocapitalize="off"`.
  The browser trying to help would destroy the entire point.
- **`isTyping()` marks Butterfingers as a different kind of round.** It takes a
  separate path through `beginRound`, carries `kind: "typing"` on the round and
  the view, and is exempt from the render-differs-from-clean invariant — its
  barrier lives in the input pipeline, not the render. `mangle` returns an empty
  token set with `mode: "typing"` so nothing downstream has to special-case it.
- **In solo, the scribe simply stops the mangling.** The true keyboard handover
  to another participant is S18, which reuses this same accommodated path.

## Notes

Dictation prompts live in their own array in `passages.js` — a typing task needs
a different shape from a reading passage. The full set of 10 arrives in S8.

The caret is restored to the end of the input after each re-render, since the
reducer round-trip rebuilds the node on every keystroke.
